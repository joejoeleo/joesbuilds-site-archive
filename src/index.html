Flagship Project

Infinity Entertainment Table

My RIT senior capstone and the clearest example of how I like to work: start with an ambitious physical product, keep the design practical, and build enough of the system to prove it.

Role Project manager and lead designer
Team Multidisciplinary RIT capstone team
System Infinity LED table with five-drink dispensing

Built as a table first

The project had to work as furniture before it could work as a machine. The final build combines a table structure, wood surfaces, clear access panels, an infinity lighting feature, drink storage, tubing, controls, and a touchscreen interface.

Controls inside the object

The drink system uses Raspberry Pi controls, custom PCBs, and 3D-printed parts. The electronics and dispensing hardware had to fit inside the table without turning the object into a loose collection of parts.

Three design iterations

I led the team through three design iterations, using Fusion 360 to work through layout, packaging, and the relationship between the visible product surfaces and the internal dispensing system.

What I owned

I was elected project manager and lead designer. My role covered the product layout, mechanical direction, team coordination, design revisions, and keeping the build moving toward a working final prototype.
