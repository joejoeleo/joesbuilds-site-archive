01 / THE IDEA

What if a coffee table could dispense drinks?

The Infinity Entertainment Table brings drink dispensing, infinity lighting, and a can crusher into a piece of furniture. A touchscreen connects the person using it to the mechanisms underneath.

FROM IDEA TO ASSEMBLY

Five bottles, independently controlled pumps, and routed tubing handle the drinks. A Raspberry Pi, custom PCBs, and a touchscreen bring the systems together.

+

RIT Senior Capstone

Infinity Entertainment Table

Infinity LED table with touchscreen controls, an integrated can crusher, and a five-bottle drink dispensing system.

Role
Project manager and lead designer
Build
Lighting, drink dispensing, can crusher, controls
Tools
Fusion 360, 3D printing, custom PCBs, Raspberry Pi

Structure

Wood frame, clear panels, internal component bays, and an infinity lighting floor.

Dispensing

Five independently controlled bottles with tubing routed through the table body.

Controls

Touchscreen interface, Raspberry Pi control, custom PCBs, pumps, and wiring.

Fabrication

Fusion 360 CAD, resin 3D printed brackets, mirrors, plexiglass, and LED assemblies.
