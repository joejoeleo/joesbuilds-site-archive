# Revival Notes

If this website needs to be brought back later:

1. Install the chosen web framework dependencies.
2. Run the local development server.
3. Review the archive folder for the original Wix reference.
4. Build or restore the new site code from `src/`.
5. Deploy only when ready.

## Possible Future Stack

- Astro for a lightweight portfolio site.
- Next.js if the site needs dynamic pages or richer app behavior.
- Plain HTML/CSS/JavaScript if the goal is maximum simplicity.

No hosting is required while this repository is used only for storage.
