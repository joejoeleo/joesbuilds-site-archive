## Recommended Architecture

Single-page portfolio for the current pass:

1. Hero
2. Flagship case study
3. Selected projects
4. About
5. Resume
6. Contact

This keeps the site simple and project-led. Full separate project pages should wait until more Infinity Table documentation and media are available.

## Visual System

- Off-white background, charcoal type, neutral borders, restrained slate-blue accent
- Desktop-first grid with large project media
- Minimal cards with 8px radius
- Hover states only where they make the interface feel more tactile
- No generated imagery, fake CAD, fake video, or fake process

## Content Gaps

- Infinity Table would benefit from the actual project title details, final demo video, CAD/process images, PCB/electronics images, and short notes on what changed across the three design iterations.
- Lumen River Desk needs real build images or video before it can become a visual feature.
- Alexa-Powered Water Dispenser needs the demo video to work properly on the site.
- RIT Baja SAE needs at least one real build or fabrication image.
